# Link widget assets

- `discord.tga`, `twitch.tga`, `patreon.tga`, and `boosty.tga` are rasterized from the corresponding [Simple Icons](https://simpleicons.org/) brand marks.
- `merfinui.tga` is a transparent white mask derived from `Media/Icons/merfinui_logo_icon.tga`.
- `weakauras.tga` is a transparent white mask derived from WeakAuras' `Media/Textures/logo_256.tga`.

The white masks are intentional: the widget rotates the MerfinUI logo and applies animated vertex colors to the WeakAuras logo.
